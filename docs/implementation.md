# 회의 코파일럿 — 현재 구현

`/`: 메모/수동 전사/브라우저 자동 저장, AI 요약·코칭, 녹음, 종료 후 편집 가능한 회의록, Markdown 내보내기.
`/meetings`: 브라우저에 저장한 회의 검색·열기·삭제, 이전 노트를 참고자료에 추가.
`/history`: 이전 Supabase 기록 화면을 보존했다. 기존 설정이 필요하다. 새 로컬 기록과 동기화하지 않는다.

## 실행

Node 24에서 `npm ci`, `npm run dev`. 기본 메모/수동 전사/종료 초안/기록은 자격증명 없이 동작한다.
실시간 AI는 `.env.example`의 값을 `.env.local` 또는 런타임 환경에 설정한다. Supabase anonymous sign-in을 활성화해야 한다.
실제 계정에서 사용 가능한 Gemini 모델을 GEMINI_LIVE_MODEL과 GEMINI_COACH_MODEL에 지정한다. 모델 지원 여부는 공급자 호출로 확인해야 한다.
브라우저에서 단기 토큰을 받은 뒤 Live WebSocket으로 연결한다. API는 Supabase JWT를 검증하며 장기 키를 반환하지 않는다.
Google API와 Live WebSocket에 대한 네트워크 접근이 필요하다. 네이티브 오디오 모델이 발화하지 않으라는 지시를 항상 준수하거나 비용을 발생시키지 않는다고 보장하지 않는다.

## 데이터와 제한

새 기록은 localStorage에 저장된다. 사용자 원본 메모와 AI 회의록을 분리하며 저장 실패를 표시한다. 브라우저 데이터 삭제/비공개 모드/저장 용량 제한에 유의하고 Markdown 내보내기로 백업한다.
AI에 전달되는 메모/참고자료는 각각 제한된 길이, 전사는 최근 최대 60개다. 회의 상태의 요약/결정/액션/열린 질문을 다음 분석에 전달한다.
동시 분석은 하나로 제한하고 대기 발언은 후속 분석에 반영한다. 저장·사용자 편집과 독립적으로 분석 결과를 병합한다.
서버 분석시간은 UI에 표시하지만 음성→카드의 전체 지연과 같지 않다. 2초/5초 목표는 아직 검증하지 않았다.
마이크와 선택한 공유 탭 오디오를 AudioWorklet에서 PCM으로 변환한다. 탭 오디오는 브라우저/OS 지원에 따라 달라진다. 끊김은 표시하고 재시작을 안내하며 자동 세션 복원은 아직 없다.
종료는 음성 전송 중단/짧은 전사 수신 대기/분석 큐 완료 후 초안을 만든다. 공급자의 지연으로 늦게 도착한 전사가 모두 수신됐다는 보장은 없다.
MCP 직접 연결, 외부 자료 검색, 클라우드 동기화, DB 마이그레이션, SSE 코칭 스트리밍은 후속 구현이다. 참고자료 붙여넣기와 자체 이전 노트로 맥락 흐름을 검증할 수 있다.
기존 Deepgram 장기 키 반환 API 및 오래된 Gemini 코칭 API는 410으로 종료했다. 기존 prompt 쓰기 API도 body.userId 대신 검증한 JWT의 사용자를 사용한다.

## 검증

`node --experimental-strip-types tests/coach.test.mjs`（6개의 이름 있는 테스트 실행을 확인）
`npx tsc --noEmit`
`npm run lint`
`npm run build`

브라우저 검증: 메모/발언 입력→종료→회고 편집/확정→새로고침→기록 검색/다시 열기. 설정 없는 AI 요청은 명시적 오류이며 성공으로 표시하지 않는다.

현재 실행 결과: 타입 검사, 린트, 프로덕션 빌드, 큐/근거/저장 관련 6개 테스트가 통과했다. 로컬 Chromium에서 메모·전사·설정 부재 오류·종료·편집·확정·새로고침·기록 다시 열기·Markdown 다운로드·모바일 가로 넘침 없음·API 보호 응답을 확인했다. 브라우저 JavaScript 오류는 없었다. 실제 공급자 음성/API 호출 검증을 대신하지 않는다.

기존 수동 테스트 파일의 하드코딩 키는 제거했다. 이미 저장소 이력에 노출된 키는 공급자 콘솔에서 폐기·재발급해야 한다.
